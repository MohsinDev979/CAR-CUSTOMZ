# CAR CUSTOMZ

A responsive browser-based 3D garage and circuit-driving prototype.

## Included in the current build

### Vehicles and showroom
- Eight separately shaped fictional vehicle presets: hypercar, supercar, JDM coupe, muscle car, luxury sedan, off-road SUV, classic coupe and formula racer.
- A garage picker and collection page with silhouette previews for every vehicle.
- A procedural 3D showroom with physically based paint materials, studio environment reflections, adjustable camera and quality presets.

### Customization
- Paint palette with gloss, metallic, matte and pearl finishes.
- Multiple wheel styles, rim sizing, brake-caliper colours and front/rear camber.
- Stock or wide-body stance, selectable rear wings, front splitters, rear diffusers and hood details.
- Twin, race and side liveries with decal colours.
- Underbody neon colours, headlight temperatures, interior trim and seat-insert colours.
- Single, dual and quad exhaust tips.
- Engine output, gear ratio, traction, suspension, brake-force and tire-compound tuning.

### Driving
- Three fictional circuits: Coastline, Desert and Night City.
- Raised circuit-side barriers and track-edge collision limits.
- Touch controls with pointer capture and simultaneous two-finger steering/throttle input.
- Reverse, brake, handbrake, steering, camera modes, pause and manual gear buttons.
- Keyboard driving controls on desktop.
- Lap and speed HUD.

### Device support
- Responsive mobile and desktop UI.
- Adaptive, Ultra, High, Medium and Low visual presets.
- Local-device settings/build persistence.
- PWA manifest, SVG app icon and versioned service-worker shell cache.

## Run

This is a static web application. Serve the repository root with any static web server or deploy it to Vercel. Three.js and its examples are imported from jsDelivr, so the first 3D load requires internet access. Open on mobile in an up-to-date Chrome browser with WebGL 2 enabled.

## Important scope note

This is an improved playable prototype, not a finished commercial simulator. The models and tracks are procedurally generated, not photogrammetry or licensed production-grade vehicle assets. High-end production work still required includes professionally authored vehicle meshes and interiors, high-resolution PBR texture sets, HDR environment and track assets, full tire/suspension/rigid-body physics, engine and environment audio, AI opponents, damage, weather simulation, cloud saves, multiplayer and a packaged Windows executable.
